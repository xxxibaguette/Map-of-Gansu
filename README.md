# 传教士历史地图交互系统 (Historical Map Interaction System)

这是一个基于 **Leaflet.js** 开发的轻量级、数字人文地理信息交互系统。该系统旨在通过交互式地图，展示 17 世纪意大利传教士在中国西北地区的行迹、地名考证及相关历史文献。

---

## 📁 文件结构说明

| 文件名 | 角色 | 核心功能说明 |
| :--- | :--- | :--- |
| **index.html** | 主程序 | 系统的“大脑”，包含 UI 界面、地图初始化逻辑、搜索算法及筛选器功能。 |
| **data.js** | 数据库 | 存储所有地理坐标、中外文献对照、历史描述及点位分类数据。 |
| **map.jpg** | 资源图 | 系统底层使用的高清历史手绘地图扫描件。 |
| **sw.js** | 插件 | Service Worker 脚本，负责实现离线访问（PWA），确保断网时地图依然可用。 |

---

## ✨ 核心功能

* **高清地图坐标系**：基于像素坐标 (`CRS.Simple`)，精准还原手绘古地图的点位。
* **智能搜索与补全**：支持中英文/拉丁文双语搜索，点击建议项可自动定位并弹出文献。
* **动态分类筛选**：可根据“地名”、“备注”、“背景”、“符号”四类图标实时切换显示。
* **聚类标记 (Marker Clustering)**：当地图点位密集时自动聚合，保持视觉清爽。
* **离线存储 (PWA)**：首次访问后，系统会自动缓存图片及数据，支持完全离线查看。
* **坐标拾取工具**：点击地图任意位置，底部自动生成对应坐标，方便开发者添加新点位。

## 🛠️ 维护与更新指南

### 1. 如何添加新的地理点位？
在本地运行系统后，点击地图上的目标位置，复制底部生成的坐标代码，将其添加到 `data.js` 的数组中：

```javascript
{ 
    coord: [纵坐标, 横坐标], 
    type: 'place', 
    title: "地名", 
    desc: "历史文献描述", 
    latin: "原文对照" 
},

2. 更新数据后如何生效？
由于系统开启了 Service Worker 缓存，修改 data.js 后，必须修改 sw.js 文件第一行的版本号（例如从 v1.2 改为 v1.3），否则浏览器会继续显示旧版数据。


🚀 发布方式
该项目为纯静态网页，无需服务器后端。

推荐平台：Vercel, GitHub Pages 或 Netlify。

注意事项：由于涉及 Service Worker，必须在 HTTPS 环境下运行才能激活离线缓存功能。

本地预览：建议使用 VS Code 的 Live Server 插件启动，不要直接双击 HTML 文件。
